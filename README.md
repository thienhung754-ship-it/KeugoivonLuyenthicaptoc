# Pitch Deck Gọi Vốn — luyenthicaptoc.vn

Slide thuyết trình tương tác phục vụ pitch deck gọi vốn vòng Angel (500 Triệu / 10%) nền tảng Luyện Thi Cấp Tốc (Mercy Tech).

## Tính năng nổi bật
- Slide tỷ lệ 16:9 full màn hình, auto-scaling theo mọi độ phân giải màn hình máy chiếu/laptop.
- Animation tự động chạy tuần tự khi chuyển slide (auto-run sequence).
- 1 Click = 1 Slide (chuẩn clicker thuyết trình).
- Tích hợp WebGL 3D Math Engine tương tác xoay 360 độ.
- Tích hợp bộ đề thi mẫu A4 chuẩn hóa Bộ GD&ĐT.
